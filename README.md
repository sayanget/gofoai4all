# Antigravity Workflow Core - 物流 AI 智能诊断与分发引擎

本项目是一个集成了大语言模型（LLM）的智能化物流诊断系统，旨在通过自动化流水线读取底层 TMS（运输管理系统）等物流节点数据，运用 AI 专家引擎对各项时效指标进行深度剖析定责，并将最终诊断考核报告转化为原生排版推送至「飞书」生态。

## 🌟 核心特性

- **🤖 AI 专家深度诊断**：无缝对接 OpenAI 兼容格式的各类大语言模型，并支持**场景预设与自定义系统提示词 (Prompt)**。AI 可以根据不同的环境模式（如：双十一严格模式、淡季鼓励模式）产出带有情绪倾向和深度分析的定责报告。
- **📊 动态红线与规则管理**：完全配置化驱动。内置统一的系统规则库 (`config/rules.json`)，支持在前端控制面板上直观地**动态增删修改指标**并实时调整报警红线（如发车准点率、卸车及时率等）。
- **📬 飞书原生卡片推送**：报告结果告别粗糙的文本拼接，使用飞书最新的 **JSON 2.0 表格组件**重构渲染引擎。排版规整，兼容多端（PC/Mobile），支持自定义 Webhook 机器人及企业自建应用双通道分发。
- **🧠 智能规则解析 (Extractor)**：无需人工录入复杂的业务规则！控制台自带规则解析器，支持上传管理规范文档（图片/文本），由 AI 自动抽取结构化的考核指标与车辆装载上限配置。
- **⚙️ 全局一站式控制台**：提供了一个精致且现代化的浏览器 Web UI (Glassmorphism 风格)，在一处完成所有通道鉴权、大模型参数调优、指标阈值设定及历史快照的回滚。

## 🚀 快速启动

系统专为 Windows 环境打造了便捷的启动脚本。

1. **一键启动系统**：
   在项目根目录下双击运行 **`一键启动服务.bat`**。
2. **初始化配置**：
   脚本会自动在后台启动 Python Flask 服务引擎 (默认 `9999` 端口)，并在 3 秒后自动唤起您的默认浏览器进入核心控制台：
   👉 `http://127.0.0.1:9999`
3. **配置凭证信息**：
   在系统控制台中：
   - 填入您的 `LLM API Key` 及模型调用地址（默认支持 `gpt-4o` 兼容接口）。
   - 选择飞书通知分发通道，填入 Webhook 地址或飞书开放平台应用凭证。
4. **生成与推送**：
   点击卡片底部的 **“运行诊断并生成报告结论”**，随后即可前往独立编辑器二次预览与推送至飞书群聊。

## 📁 目录结构简析

- `feishu_config.html` & `card_editor.html`: 前端核心交互控制面板与卡片编辑器。
- `server.py`: 基于 Flask 打造的轻量级后端，负责前后端的数据接口互通及规则落地。
- `llm_analyzer.py`: 大模型诊断核心层，负责提示词的拼接、动态兜底以及 API 异常处理。
- `run_pipeline.py`: 后台调度流水线，负责驱动整体爬取、计算、诊断与下发的全生命周期。
- `feishu/card_sender.py`: 飞书消息分发组件，负责将 JSON 报告转化为排版精美的卡片格式。
- `config/`: 系统的状态存储与核心静态配置（如 `rules.json` 及大模型通道 `feishu_config.json`）。

## 🤝 贡献与维护

目前该库作为调度专家 AI 工作流的落地雏形，由 Antigravity Agentic 体系维护并持续进化。如需添加新的静态指标考核算法，建议直接在控制台的“静态规则库管理”栏目操作，或安全地修改 `rules.json` 配置表。
